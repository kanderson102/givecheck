# GiveCheck — Marketing Launch Plan

_Deferred items from the main todo list. Tackle these when the core product is stable._

---

A launch sequence that will help us get our first 1000 members. It involves building a machine to get our first 100 members, then using that momentum to get the next 900.

It starts with a pre-launch phase, then a launch phase, then a post-launch phase. 

Pre-launch means building up the machine and going through some test runs to work out any kinks and see what needs to be improved. It means teasing it to the world by beginning to show the badge on my own site and beginning to talk about it on social media. 

We want to have a waitlist of 1000+ people before we officially launch. The first 100 people will allow us to test the onboarding process and make sure it's smooth. With real users and data we can fill out the leaderboard and make it look like a real product. 

Next the official launch will look like a coordinated effort across all the platforms we've built relationships with. We'll ask them to make a coordinated post about GiveCheck on launch day. 

The next 900 will allow us to test the scaling process and make sure it's smooth. At the end of this phase we'll make another coordinated effort to officially launch GiveCheck on Product Hunt and Hacker News. 

Post launch we'll continue to build relationships with larger companies and influencers to continue to grow the community. This will be an ongoing process but some major things we want to accomplish include getting on podcasts and promoting a hackathon that GiveCheck will donate for prizes to build open source tools for nonprofits and ecological technology (put this in vision and about pages with photos).
