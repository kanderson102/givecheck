# Story: P0.4 — Verification Loop & Leaderboard

**As a** GiveCheck user who pledged $X/mo to nonprofits,
**I want** my badge to flip to "verified" after a 30-day period closes with donations confirmed,
**so that** I can embed a live, credible badge and appear ranked on the leaderboard.

---

## Acceptance criteria

### Pledge
- [x] Setting a pledge stores `pledgedMonthlyCents` (not just %)
- [x] Pledge < $10 is rejected with a clear message
- [x] Pledge with odd cents (e.g. $10.50) is rejected ("whole dollars only")
- [x] Dashboard pledge page shows "$X/mo (≈N% of MRR)" when MRR is known

### Donation links
- [x] `/api/donations/process` returns `donationUrl` per allocation based on fixed dollar split
- [x] Any allocation < $10 returns a 400 with `undersized` array in response
- [x] `partnerDonorId` in every Every.org URL equals the company's UUID

### Webhook
- [x] `POST /api/every-org/webhook` returns 401 with wrong/missing signature
- [x] Valid payload upserts into `donations` (run twice → still 1 row)
- [x] `donation.refunded` flips `status = "refunded"` without deleting the row
- [x] `subscription.cancelled` sets `everyOrgSubCancelledAt` on the company
- [x] Payload without `partnerDonorId` matching a company is ignored (200, `ignored`)

### Cron
- [x] `GET /api/cron/daily` returns 401 without `CRON_SECRET` header
- [x] With correct header: returns 200 + JSON summary
- [x] A period ending yesterday with total donations >= pledgedCents flips `is_verified = true`
- [x] A period ending 8 days ago with short donations flips company `status = "lapsed"`
- [x] A period ending 3 days ago with short donations stays "verified" (grace, retry tomorrow)

### Badge (`/api/badge`)
- [ ] Returns `status: "pending"` before first period closes
- [ ] Returns `status: "verified"` after cron runs on a verified company
- [ ] Returns `status: "lapsed"` after 7-day grace expires
- [ ] Returns `verifiedStreak` count + `categoryLeaderDays` (null if not leader)

### Leaderboard
- [ ] "This week" tab shows `donatedLast7dCents` correctly ranked
- [ ] "All time" tab shows `derivedPledgePct` + `pledgedMonthlyCents`
- [ ] Category filter dropdown works
- [ ] "Verified today" section shows companies verified within last 24h

### Drift banner
- [ ] Dashboard shows a banner when `mrrDriftFlag = "grew"` with MRR delta %
- [ ] Dashboard shows a different banner when `mrrDriftFlag = "dropped"`
- [ ] Banner dismisses (resets flag) when user clicks "Got it"

## Test plan (manual — run after each PR in this story)

### 1. Pledge validation
```bash
# Requires running dev server + logged-in Clerk session cookie
curl -X POST http://localhost:3000/api/dashboard/pledge \
  -H "Content-Type: application/json" \
  -H "Cookie: <clerk_session>" \
  -d '{"pledgedMonthlyCents": 999}'
# → 400: "Pledge must be at least $10"

curl ... -d '{"pledgedMonthlyCents": 1050}'
# → 400: "Pledge must be a whole-dollar amount"

curl ... -d '{"pledgedMonthlyCents": 5000}'
# → 200: { pledgedMonthlyCents: 5000, derivedPct: ... }
```

### 2. Webhook idempotency
```bash
# Get EVERY_ORG_WEBHOOK_SECRET, compute HMAC of body, then:
PAYLOAD='{"type":"donation.succeeded","partnerDonorId":"<company_uuid>","id":"test-001","amountCents":5000,"recipientName":"Test Org","recipientSlug":"test-org","createdAt":"2026-04-17T12:00:00Z"}'
SIG=$(echo -n "$PAYLOAD" | openssl dgst -sha256 -hmac "$EVERY_ORG_WEBHOOK_SECRET" | awk '{print $2}')
curl -X POST http://localhost:3000/api/every-org/webhook \
  -H "Content-Type: application/json" \
  -H "every-org-signature: $SIG" \
  -d "$PAYLOAD"
# → { ok: true }
# Run twice, confirm donations table has 1 row, not 2
```

### 3. Cron
```bash
# Manually set a verification_period.period_end to yesterday in DB, then:
curl -H "Authorization: Bearer $CRON_SECRET" http://localhost:3000/api/cron/daily
# → { ok: true, summary: { verified: 1, ... } }
```

### 4. Badge
```bash
curl http://localhost:3000/api/badge?slug=<company_slug>
# → { status: "verified", pledgedMonthlyCents: 5000, verifiedStreak: 1, ... }
```
